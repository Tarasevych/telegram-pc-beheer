# Security policy

Do not open public issues containing bot tokens, Telegram IDs, SSH hostnames, key paths, IP addresses, audit logs, MTProto sessions, provider IDs, or smart-home credentials.

If a bot token is exposed, revoke it immediately through BotFather, replace the Windows Credential Manager value, restart `TelegramBeheer`, and review the audit log and Telegram Devices.
