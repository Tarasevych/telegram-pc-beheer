# Tarasevych GPT — керування ПК через Telegram

**Мова:** Українська | [Nederlands (Нідерландська)](LEESMIJ.nl.md) | [Двомовний огляд (README.md)](README.md) | [Політика безпеки (БЕЗПЕКА.uk.md)](БЕЗПЕКА.uk.md)

Це приватний центр віддаленого керування власним персональним комп'ютером під керуванням Windows через Telegram. Мова спілкування з користувачем — чиста українська; технічні шляхи, службові файли та ідентифікатори в коді, де кирилиця недоречна, оформлено нідерландською мовою.

## Основні можливості

- доступ виключно для власника за точним числовим ідентифікатором у приватній бесіді Telegram;
- кнопки перегляду стану комп'ютера, активних процесів, мережі, накопичувачів, з'єднань SSH, середовища Codex, журналу аудиту та розумного дому;
- виконання довільних команд PowerShell лише після свіжого підтвердження кнопкою, яке діє протягом 2 хвилин;
- виклик локального засобу командного рядка Codex у визначеній робочій теці з обмеженням запису `workspace-write`;
- покроковий майстер додавання з'єднань SSH із полями: видима назва, адреса `user@host`, порт і шлях до криптографічного ключа;
- зберігання ключа доступу бота виключно у системному сховищі облікових даних Windows;
- ведення журналу аудиту в SQLite, автоматичне приховування таємних даних у тексті виводу та захист від одночасного запуску другого примірника служби;
- заплановане завдання Windows із автоматичним запуском під час входу, перезапуском після збоїв і безперервною роботою від акумулятора;
- пряма кнопка переходу до окремого бота розумного дому, підготовлена зворотна кнопка в його локальному коді та незалежний від постачальника договір обміну подіями.

## Швидка локальна перевірка

```powershell
& '..\.venv\Scripts\python.exe' -m unittest discover -s tests -v
& '.\installeren.ps1'
Get-ScheduledTask -TaskName TelegramBeheer
```

Для перевірки під'єднання до справжнього віддаленого пристрою через SSH потрібні дійсні реквізити: адреса вузла, ім'я користувача, номер порту та дозволений ключ. Ці відомості навмисно ніколи не зберігаються у відкритому сховищі на GitHub.
