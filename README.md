# Telegram PC Beheer / Керування ПК через Telegram

[Українська документація](README.uk.md) · [English documentation](README.en.md)

Відкритий код приватного Telegram-контуру для керування власним Windows ПК: стан системи, SSH-клієнт, підтверджені PowerShell-команди, Codex GPT, аудит і безпечний міст до окремого бота розумного будинку.

Public source for an owner-only Telegram control plane for a Windows PC: system status, outbound SSH, confirmed PowerShell commands, Codex GPT, audit logging, and a safe bridge to a separate smart-home bot.

No production token, Telegram owner ID, SSH private key, host address, MTProto session, local audit database, or smart-home provider credential is committed to this repository.
