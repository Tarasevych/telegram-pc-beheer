## 🇺🇦 Українською

Відкритий вихідний код приватного контуру в Telegram для віддаленого керування власним персональним комп'ютером під керуванням Windows: перевірка стану системи, клієнт захищених з'єднань SSH, виконання команд PowerShell із обов'язковим підтвердженням, виклик локального засобу Codex ШІ, ведення журналу аудиту та безпечний міст до окремого бота розумного дому.

Жоден робочий ключ доступу бота, особистий ідентифікатор власника в Telegram, закритий криптографічний ключ SSH, адреса віддаленого вузла, дані сеансу MTProto, локальна база даних аудиту чи облікові дані постачальників розумного дому ніколи не зберігаються у цьому відкритому сховищі.

## 🇳🇱 In het Nederlands

Openbare broncode voor een persoonlijk Telegram-besturingscentrum voor een eigen Windows-pc: systeemstatus, uitgaande SSH-verbindingen, bevestigde PowerShell-opdrachten, Codex GPT, logboekregistratie en een veilige koppeling naar een afzonderlijke bot voor de slimme woning.

Geen enkele actieve toegangssleutel, Telegram-eigenaarsidentificatie, privésleutel voor SSH, serveradres, MTProto-sessie, lokale SQLite-gegevensbank of aanmeldgegevens voor de slimme woning worden in deze openbare opslagplaats opgeslagen.
