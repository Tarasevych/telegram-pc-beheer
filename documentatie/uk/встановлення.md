# Встановлення і налаштування

**Мова:** Українська | [Nederlands (Нідерландська)](../nl/installatie.md) | [Український огляд (README.uk.md)](../../README.uk.md) | [На головну (README.md)](../../README.md)

## Необхідні передумови

- Операційна система Windows 11, інтерпретатор Python 3.13 або сумісна версія Python;
- встановлений пакунок `keyring`;
- системний клієнт OpenSSH для Windows;
- локально встановлений і авторизований засіб командного рядка Codex;
- власний бот у Telegram, створений через офіційного `@BotFather`.

## Таємні дані та конфігурація

1. Скопіюйте зразок `configuratie/instellingen.voorbeeld.json` у робочий файл `configuratie/instellingen.json`.
2. Зазначте точний числовий ідентифікатор власника в Telegram та шлях до робочої теки.
3. Запустіть допоміжний сценарій `gereedschap/configureren.py`. Ключ доступу бота вводиться без відображення символів на екрані та записується безпосередньо до системного сховища облікових даних Windows (служба `TelegramBeheer`, запис `bot_token`).
4. Ніколи не додавайте робочі файли `instellingen.json` або `ssh-doelen.json` до системи контролю версій Git.

Український опис профілю бота та перелік його команд встановлюються автоматично під час кожного запуску служби.

## Автоматичний запуск

Сценарій `installeren.ps1` реєструє системне завдання `TelegramBeheer` для поточного облікового запису користувача. Воно працює з обмеженим рівнем повноважень, не припиняє роботу під час переходу комп'ютера на живлення від акумулятора, унеможливлює одночасний запуск дублікатів і автоматично перезапускається в разі непередбаченого збою.

```powershell
& '.\installeren.ps1'
Get-ScheduledTask -TaskName TelegramBeheer
Get-ScheduledTaskInfo -TaskName TelegramBeheer
```

## Налаштування через BotFather

Рекомендовано встановити українську видиму назву, опис і підписи команд. Технічне ім'я бота в Telegram має складатися з латинських літер і закінчуватися на `bot`. Отриманий ключ доступу слід одразу зберегти у сховищі облікових даних Windows і ніколи не залишати в нотатках, переписці, файлах середовища `.env` або у відкритому сховищі коду.
