# Інтеграція з Tarasevych Slimme Woning

Два боти навмисно мають різні BotFather-ідентичності, токени, runtime та права. Бот дому керує лише прийнятими capability-маршрутами й не передає свої provider-секрети GPT-боту.

Рівні інтеграції:

1. У GPT-боті live працює URL-кнопка до бота дому. Зворотна кнопка додана до локального `Code.gs`, пройшла 123/123 тести, але має бути опублікована разом із поточним Apps Script release; це не можна видавати за live deployment.
2. Спільна семантика статусів і локальний JSONL-потік подій.
3. Майбутній адаптер до локального ядра через MQTT або підписаний HTTPS.
4. Незалежний Telegram/Apps Script/Tuya канал дому продовжує працювати, якщо ПК-бот вимкнений.

Bots API не доставляє повідомлення одного бота іншому. Спроба «з’єднати ботів через чат» не є резервним транспортом. Правильний резерв — незалежний адаптер із власною автентифікацією, дедуплікацією `bericht_id`, порядком `opstart_id + volgnummer` і свіжим фізичним readback.
