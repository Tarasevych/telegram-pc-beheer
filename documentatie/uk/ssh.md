# SSH-підключення

На ПК потрібен лише OpenSSH Client. Бот не встановлює й не відкриває SSH Server.

Майстер `SSH → Додати SSH` послідовно запитує:

1. відображувану назву;
2. `host.com` або `user@host.com`;
3. порт чи `-` для 22;
4. повний шлях до ключа чи `-` для ssh-agent/типового ключа.

Перевірка виконує неінтерактивний `ssh` із `BatchMode=yes` і `ConnectTimeout=8`. Успіх означає, що встановлено TCP-зв’язок, host key прийнятий згідно з локальною політикою та ключова автентифікація дозволена віддаленим `authorized_keys`.

Не передавайте приватний ключ у Telegram. Для першого host-key acceptance підключіться локально в довіреній мережі, перевірте fingerprint поза Telegram, а потім збережіть `known_hosts`.
