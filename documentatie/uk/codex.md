# Codex GPT

Команда `/codex запит` запускає локальний офіційний Codex CLI як окрему ephemeral-сесію. Бот знаходить актуальний `codex.exe` у локальній папці застосунку, передає налаштовану робочу папку та повертає фінальний текст у Telegram.

Поточна політика:

- sandbox: `workspace-write`;
- approval: `never`, щоб headless-запуск не зависав на невидимому діалозі;
- без `danger-full-access`;
- без `--search` за замовчуванням;
- timeout із локальної конфігурації;
- довгі відповіді скорочуються перед надсиланням у Telegram.

Це дає значну частину практичного керування файлами й кодом, але не є піксельною копією всього інтерфейсу Codex Desktop. Офіційний `codex remote-control` може бути окремим резервним каналом; він не повинен ділитися токеном із Telegram-ботом.
